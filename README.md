# 🧠 Second Brain

Vault pessoal do Obsidian para aprendizado contínuo e gestão de conhecimento.

## Estrutura

| Pasta | Descrição |
|---|---|
| `00-inbox/` | Captura rápida — tudo entra aqui primeiro |
| `01-notes/` | Notas processadas (daily, permanent, literature) |
| `02-projects/` | Projetos ativos |
| `03-resources/` | Prompts, referências e recursos |
| `04-archive/` | Material arquivado |
| `05-templates/` | Templates para novas notas |

## Fluxo de trabalho

```
Captura (inbox) → Processamento (notes) → Conexão (links) → Arquivo
```

## Setup

- **Sync:** Obsidian Git → Gitea (auto-commit a cada 10 min)
- **IA:** GitHub Copilot Pro + MCP
- **Templates:** Templater plugin
- **Queries:** Dataview plugin

## Modelos de IA configurados
